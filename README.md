# مشكاة لانشر | Mishkat TV Launcher 📺✨

> **مِشكاة** — لانشر تلفزيوني ذكي بتصميم زجاجي سائل (Liquid Glass) مستوحى من فلسفة Apple TV، مخصص لأجهزة Android TV و Google TV و TV Boxes.

---

## 🌟 الميزات الرئيسية (Key Features)

- 📺 **دليل القنوات الفضائية المباشرة (Live Satellite TV - NileSat)**:
  - بث حي ومباشر (HLS / m3u8) بدقة 1080p و HD لأقوى القنوات المصنفة:
    - **باقة الأطفال**: سبيس تون، كرتون نتورك بالعربية، كوكيز / كوجي كيدز، إم بي سي 3، وناسة كيدز، أطفال ومواهب، سات 7 كيدز.
    - **باقة السينما والأفلام**: روتانا سينما مصر، روتانا كلاسيك، روتانا كوميدي، روتانا كليب، ميكس هوليوود، إم بي سي 4، إم بي سي بوليوود.
    - **باقة الدراما والمسلسلات**: روتانا دراما، إم بي سي مصر 1 و 2، إم بي سي دراما، إم بي سي 1.
    - **باقة القرآن الكريم والقنوات الإسلامية**: بث مباشر من الحرم المكي الشريف، والمسجد النبوي بالمدينة المنورة، وإذاعة القرآن الكريم من القاهرة، وقناة الشارقة قرآن، والرسالة، واقرأ.
    - **باقة القنوات العامة والأخبار والرياضة**: الفضائية المصرية، قناة الغد، تلفزيون الشارقة، قناة العربية، سكاي نيوز عربية، الشرق الوثائقية، والشارقة الرياضية.
  - مشغل فيديو داخلي سريع مع قائمة قنوات جانبية سريعة بضغطة زر `OK` وتقليب فوري للأعلى والأسفل.

- 📻 **الإذاعة وقراء القرآن الكريم (Media3 Audio Engine)**:
  - إذاعة متواصلة 24/7 مع خدمة تشغيل في الخلفية `MediaSessionService`.
  - قائمة سريعة لأشهر قراء مصر والعالم الإسلامي ومؤقت نوم ذكي قابل للضبط.

- 🕌 **مواقيت الصلاة والأذكار التفاعلية**:
  - حساب فلكي دقيق لمواقيت الصلاة الخمس مع عداد تنازلي للصلاة القادمة.
  - أذكار الصباح والمساء وأذكار بعد الصلاة ومسبحة إلكترونية تفاعلية بضغطة زر الريموت.

- 🎮 **نظام التنقل الذكي وزر الهوم (Accessibility Home Key)**:
  - محرك تنقل فائق السرعة عبر الأسهم (D-Pad) بدون تعليق مع تركيز مرئي واضح.
  - خدمة إمكانية وصول مدمجة (`MishkatAccessibilityService`) تبرمج زر `Home` في الريموت للعودة دائماً لمشكاة وتمنع الخروج للانشر النظام الأصلي.

- 📱 **ريموت الموبايل عبر الواي فاي (QR Code)**:
  - خادم محلي مدمج يتيح التحكم الكامل في اللانشر من أي متصفح هاتف بمجرد مسح كود QR دون الحاجة لتثبيت أي تطبيقات.

- ⚡ **أداء خفيف واستهلاك إنترنت منخفض**:
  - تقليص الحجم عبر ProGuard و R8 بحجم 7.6 ميجابايت فقط.
  - دعم أنظمة أندرويد من **Android 7.0 (Nougat / API 24)** وحتى **Android 15 (API 35+)**.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Language**: Kotlin 2.1
- **UI Toolkit**: Jetpack Compose for TV (`androidx.tv.material3`) + Liquid Glass Custom Modifiers
- **Media Playback**: AndroidX Media3 (ExoPlayer + HLS Module + Session Service)
- **Background & Audio**: Foreground Service (`mediaPlayback`)
- **System Integration**: Android AccessibilityService for Remote Key Interception (`KEYCODE_HOME`)
- **Local Storage**: Jetpack DataStore Preferences
- **Build System**: Gradle 8.11 with Kotlin DSL & R8 Minification
