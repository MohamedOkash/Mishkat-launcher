# قائمة فحص وقياس Sprint S1 (مشغل الإذاعة والقراء + مؤقت النوم) على Mi Box S 2

## 1) التثبيت والتشغيل الأولي Offline (R3)
```powershell
D:\Android\Sdk\platform-tools\adb.exe install -r app\build\outputs\apk\debug\app-debug.apk
```
- [ ] افصل الـ Wi-Fi عن الجهاز وافتح اللانشر: يظهر شريط **NowPlayingBar** ورف **إذاعات القرآن والقراء** (177 إذاعة) فورًا بدون إنترنت.

## 2) البث الخلفي وأزرار الريموت (R12 / §10 DoD)
أعد توصيل الـ Wi-Fi وراقب اللوج:
```powershell
D:\Android\Sdk\platform-tools\adb.exe logcat -s "[Mishkat Radio]:D" "[Mishkat System]:D"
```
- [ ] اختر قارئًا من رف القراء أو من لوحة **كل القراء (177)** واضغط **OK**: يبدأ البث الصوتي خلال ثوانٍ.
- [ ] اضغط زر **Play/Pause** و **Next / Previous** والأرقام **1..9** في الريموت: يستجيب المشغل فورًا.
- [ ] افتح تطبيقًا آخر (مثل Settings أو YouTube بدون تشغيل فيديو) أو اترك اللانشر في الخلفية لمدة **30 دقيقة**: يستمر البث عبر `RadioPlaybackService` بدون انقطاع.
- [ ] شغّل فيديو في تطبيق آخر: يتوقف صوت الإذاعة تلقائيًا احترامًا لـ Audio Focus (R12).

## 3) المفضلة ومؤقت النوم الموحد (R13)
- [ ] أضف قارئًا للمفضلة (`★`) ثم أعد تشغيل الجهاز: يظل القارئ في مقدمة القائمة وتحت تبويب المفضلة.
- [ ] فعّل **مؤقت النوم** (15د / 30د / 60د): يظهر العد التنازلي في الشريط العلوي، وفي آخر 5 ثوانٍ ينخفض الصوت تدريجيًا (`Fade-out`) ثم يتوقف البث تمامًا.
