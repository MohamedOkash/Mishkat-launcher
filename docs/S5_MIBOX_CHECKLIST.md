# قائمة التحقق النهائية (Sprint S5 — الإصدار 1.0.0-s5 على Xiaomi Mi Box S)

تُستخدم هذه القائمة للتحقق النهائي من معايير القبول (**§10 Definition of Done**) على جهاز Xiaomi Mi Box S (2GB RAM):

## 1. أوامر البناء والفحص الآلي
```powershell
$env:JAVA_HOME='D:\Android\jdk-21'
$env:ANDROID_HOME='D:\Android\Sdk'
.\gradlew.bat testDebugUnitTest assembleDebug assembleRelease
```

## 2. فحص الأداء والذاكرة على الجهاز الحقيقي (ADB)
1. **تثبيت نسخة Release**:
   ```powershell
   adb install -r app\build\outputs\apk\release\app-release-unsigned.apk
   ```
2. **قياس استهلاك الذاكرة (RAM PSS)**:
   ```powershell
   adb shell dumpsys meminfo com.mishkat.launcher
   ```
   - **المعيار**: `TOTAL PSS <= 120,000 KB` أثناء الراحة، و `<= 165,000 KB` أثناء البث القرآني المباشر.
3. **قياس الإطارات والتمرير السريع (Jank / Frame Timeline)**:
   ```powershell
   adb shell dumpsys gfxinfo com.mishkat.launcher reset
   # مرّر بسرعة عبر الأرفف لمدة 15 ثانية بالريموت
   adb shell dumpsys gfxinfo com.mishkat.launcher
   ```
   - **المعيار**: `Janky frames < 2%`.

## 3. قائمة التحقق الوظيفية الشاملة (§10 DoD)
- [x] **Offline-First (R3)**: افصل Wi-Fi وأعد تشغيل الجهاز → تفتح الشاشة الرئيسية كاملة مع الـ 177 محطة، مواقيت الصلاة، الأذكار، التاريخ الهجري، والطقس المخزن، والتطبيقات المثبتة.
- [x] **الإذاعة المباشرة + مؤقت النوم (S1)**: شغّل أي قارئ، اضبط مؤقت النوم، وتأكد من خفض الصوت تدريجيًا (Fade-out 5s) قبل التوقف.
- [x] **مواقيت الصلاة + شاشة الأذان (S2)**: اختر مدينتك Offline، واضغط "معاينة شاشة الأذان" للتأكد من ظهور `AdhanOverlay` فوق الواجهة.
- [x] **البانر + الطقس 7 أيام + الثيمات (S3)**: بدّل بين ثيمات (`رمال`، `نور`، `ليلى`) وتأكد من توقف حركة البانر عند فتح أي نافذة (R23).
- [x] **مدير التطبيقات واللغة الفورية (S4)**: بدّل اللغة (`EN` / `عربي`) ونظام الوقت (`12h` / `24h`) بدون إعادة تشغيل، وجرّب تثبيت (`★`) أو إخفاء التطبيقات الإعلانية.
- [x] **أدوات الجهاز الصادقة (S5 / R24)**: افتح "أدوات الجهاز" وتأكد من مطابقة قراءة الـ RAM والتخزين وحرارة المعالج للواقع، وجرّب زر تنظيف الكاش الفعلي.
